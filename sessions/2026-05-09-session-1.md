### 2. Valid Anagram (Arrays & Hashing) — Easy — Blind 75

**Status:** Solved ✅  
**Confidence:** 5/5  
**Language:** C++ (also attempted C#)

#### Key Insights
- Two strings are anagrams if they have the same character frequencies
- Used `unordered_map<char, int>` initially for general solution
- Refactored to `int[26]` for lowercase-only optimization
- Combined increment/decrement into single loop for elegance
- Early bail on length mismatch

#### Code Evolution
```cpp
// Approach 1: Hash map (general)
unordered_map<char,int> freq;
for(char c : s) freq[c]++;
for(char c : t) freq[c]--;
for(const auto& pair : freq) 
    if(pair.second != 0) return false;

// Approach 2: Array counter (optimized for a-z)
int count[26] = {0};
for(int i = 0; i < s.length(); i++) {
    count[s[i] - 'a']++;
    count[t[i] - 'a']--;
}
for(int c : count) 
    if(c != 0) return false;
```

#### Critical Thinking Points
- **Q:** Why manual loop over `std::all_of`? → Interview readability, explicit control flow
- **Q:** Space optimization? → `int[26]` is O(1) vs O(k) for hash map
- **Q:** What about Unicode? → `int[26]` breaks, must use `unordered_map`
- **Q:** Can we do O(1) extra space without hash? → Sort both strings, O(n log n) time
