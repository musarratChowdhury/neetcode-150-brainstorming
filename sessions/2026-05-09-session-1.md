### 1. Contains Duplicate (Arrays & Hashing) — Easy — Blind 75

**Status:** Solved ✅  
**Confidence:** 5/5  
**Language:** C++

#### Key Insights
- Started with `std::map<int, int>` (frequency counter approach)
- Refactored to `std::unordered_set<int>` after critical review
- Realized counting frequencies is unnecessary — existence check is sufficient
- `unordered_set` gives O(1) average vs `map`'s O(log n)

#### Code Evolution
```cpp
// Initial approach (overkill)
map<int, int> freq;
for(int num : nums) {
    freq[num]++;
    if(freq[num] > 1) return true;
}

// Final approach (cleaner)
unordered_set<int> seen;
for(int num : nums) {
    if(seen.count(num) > 0) return true;
    seen.insert(num);
}
```

#### Critical Thinking Points
- **Q:** Why not `map`? → O(log n) per op, sorted order not needed
- **Q:** Can we do O(1) space? → Sort first, but O(n log n) time trade-off
- **Q:** What if array is already sorted? → Two-pointer or adjacent check, no hash needed
